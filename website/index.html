Sync without a server

The phone and the PC talk to each other directly over the Wi-Fi network they share. There is no VaultPass account and no relay in between.

Sync works between VaultPass for Android 2.7.0 and VaultPass for Windows 1.1.0 or newer, so update both apps together. It isn't in the current releases yet.

  1. Pair once

    Open Sync in the Windows app and scan its QR code with the Android app. You approve the phone on the PC before the pairing is saved.

  2. Find each other

    With Sync open on both, they find each other on your local network and connect directly. Nothing goes through the internet.

  3. Review the changes

    The device that starts the sync shows every change side by side. The other one approves a summary.

  4. Same vault on both

    Both devices end up with the same entries, deleted ones included. Nothing was stored anywhere else.

Local network only, never the internet Every message encrypted with AES-256-GCM The pairing secret never crosses the network

What happens to your master password

Both apps turn it into a key on your own device. The password itself is never stored and never sent anywhere.

  1. You type your master password on the phone or the PC Neither app writes it down or sends it anywhere.
  2. PBKDF2 stretches it HMAC-SHA256, 300,000 rounds, random salt Every guess costs an attacker 300,000 rounds.
  3. It unwraps the data key random 256-bit key Locking the vault overwrites it in memory with zeros.
  4. The data key opens each entry AES-256-GCM A changed byte fails the authentication tag instead of decrypting.

If someone keeps guessing

The Android app makes you wait longer after each run of wrong passwords. It counts them on disk, so restarting the app doesn't reset the count.

  • 5 tries30 s
  • 10 tries60 s
  • 15 tries5 min
  • 20+ tries15 min

What nobody can do

  • Reset your master password. There is no recovery key and no server. Keep an encrypted backup somewhere safe.

  • Read your vault. The developer runs no servers, and neither app sends analytics or crash reports.

  • Know who you are. There is no account, email address or phone number.

Questions

Something else? Open an issue on GitHub for the Android app (opens in a new tab) or the Windows app (opens in a new tab).

Can you recover my master password if I forget it?

No. There is no server and no recovery key. Your vault is encrypted with a key derived from your master password, so nobody, including the developer, can reset a forgotten one. Keep an encrypted backup and a written copy of the password somewhere safe.

Does VaultPass use the internet?

Your vault is never sent to the internet or to a cloud service.

From Android 2.7.0 and Windows 1.1.0, each app has two optional network features: sync between the phone and the PC, directly over your local network after you pair them with a QR code, and an update check that asks GitHub for the latest version. The update check is off until you turn it on and sends nothing from your vault.

Earlier versions differ. Android 2.6.x has no network access at all. Windows 1.0.1 checks GitHub for a new version each time it opens; you can turn that off in Settings, under About.

Do I need both apps?

No. Each app is a complete password manager on its own. Install both if you want the same vault on your phone and your PC; from Android 2.7.0 and Windows 1.1.0 they keep each other up to date when you sync.

How do I back up my passwords without a cloud?

Export an encrypted backup and keep it on a USB drive or another computer. Both apps write .vpex files, encrypted with AES-256-GCM under a password you choose, and a .vpex from one app opens in the other when both are up to date. The Windows app can also save a .vpb backup of the whole vault.

Plain JSON, TXT and CSV exports exist too, but anyone who gets the file can read them.

What if someone keeps guessing my master password?

On Android, input locks for 30 seconds after 5 wrong passwords, 60 seconds after 10, 5 minutes after 15, and 15 minutes after 20 or more. The count is kept on disk, so restarting the app doesn't reset it.

The Windows app doesn't limit attempts yet. There, what slows a guesser down is the 300,000 rounds of PBKDF2 behind every attempt, so pick a long master password.

Does uninstalling delete my vault?

On Android, yes: uninstalling removes the app's data, vault included. Export an encrypted backup first.

On Windows, from version 1.1.0, no: the uninstaller leaves the data folder in place so a reinstall finds your vault again. Delete that folder yourself to remove everything.

How does autofill work on Android?

VaultPass registers as an Android Autofill service (Android 8.0 or newer). When an app or website shows a login form, it finds the username and password fields and suggests matching entries.

From version 2.7.0, an entry matches a website only when the page comes from a browser VaultPass recognises and is on the entry's domain, and apps only get entries you linked to them once with "Search VaultPass". Version 2.6.x also suggests entries whose title resembles the app's name, so check a suggestion before you tap it.

Windows says "Windows protected your PC". Is that normal?

Yes. The installer isn't signed with a Microsoft code-signing certificate, so SmartScreen warns the first time you run it. Check the file's SHA-256 first (the file checker above does it for you), then choose More info and Run anyway.

Why do the download links go to GitHub?

Every release is published on GitHub, and GitHub publishes a SHA-256 checksum for each file. That checksum is what this page shows and what the file checker above compares against.
