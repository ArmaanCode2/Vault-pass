Installation & Setup in 4 Steps

01

Download & Permit Install

Download the APK on your Android device. When prompted, permit your browser or file manager to install unknown apps (Settings → Apps → Special app access → Install unknown apps).

02

Initialize Master Password

Choose a strong master password or passphrase. This key seeds your PBKDF2 key derivation. Because VaultPass has zero backdoors, write down or memorize this password carefully.

03

Enable Hardware Biometrics

Inside Settings, toggle Biometric Unlock. Authenticate with your fingerprint or face to wrap the Software DEK within Android Keystore hardware.

04
Optional

Activate Native Autofill (Optional)

If you want instant login filling across other apps and web browsers, go to your Android Settings → Passwords & Accounts → Autofill service and select VaultPass.
