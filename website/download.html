Coming from VaultPass 2.6.x? Version 2.7.0 is the first build signed with the project's release key, so Android won't install it over 2.6.x. This is needed once.

Warning: If you can't unlock VaultPass 2.6.x, do NOT uninstall it: uninstalling deletes the vault. Contact us via GitHub issues first.

If you can unlock it: export a backup in VaultPass 2.6.x (an encrypted .vpex file is safest), uninstall it, install 2.7.0, then import the backup.

Later versions install over 2.7.0 as usual, also from inside VaultPass. The first in-app update shows Android's confirmation; later ones may install without it, and VaultPass just closes. Open it again to use the new version.

Verify the download

Run one of these in the folder where the APK was saved. The output should match the SHA-256 checksum above, character for character.

Windows (PowerShell):
Get-FileHash .\VaultPass.apk -Algorithm SHA256
Linux:
sha256sum VaultPass.apk
macOS:
shasum -a 256 VaultPass.apk

Install and set up in 4 steps

01

Download & Permit Install

Download the APK on your Android phone. When Android asks, allow your browser or file manager to install unknown apps (Settings → Apps → Special app access → Install unknown apps).

02

Create your master password

Pick a strong password or passphrase. VaultPass derives your encryption key from it with PBKDF2. Nobody can reset it for you, so memorize it or write it down somewhere safe.

03

Turn on biometric unlock

In Settings, switch on Biometric Unlock and confirm with your fingerprint or face. VaultPass then protects a copy of its data key with an Android Keystore key.

04
Optional

Turn on Autofill

To fill logins in other apps and browsers, open Android Settings → Passwords & accounts → Autofill service (the path varies by phone) and choose VaultPass.
