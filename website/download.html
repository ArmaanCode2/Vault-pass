VaultPass is under active development. Keep your own encrypted backup of your vault, and update both apps at the same time if you sync them: a new version of one may not sync with an older version of the other.

Install on Android

The APK comes from GitHub Releases, not the Play Store, so Android asks for permission the first time.

Uninstalling deletes the vault. Export an encrypted .vpex backup before you uninstall or reset the app.

Coming from VaultPass 2.6.x? Version 2.7.0 is the first build signed with the project's release key, so Android won't install it over 2.6.x. You only have to reinstall this one time.

If you can't unlock VaultPass 2.6.x, do not uninstall it. Uninstalling deletes the vault. Contact us through GitHub issues (opens in a new tab) first.

If you can unlock it: export an encrypted .vpex backup in 2.6.x, uninstall it, install the new version, then import the backup.

The current Android release, 2.6.x, doesn't sync with the Windows app and has no update check. Get new versions from this page.

  1. Download the APK

    Open this page on your phone and tap Download APK. The file comes straight from the project's GitHub releases.

  2. Check the file

    Compare its SHA-256 with the one above. The file checker below does this in your browser, on the phone or on a computer.

  3. Allow the install

    Open the APK. Android asks you to let your browser or file manager install unknown apps. Allow it, and turn it off again after the install if you like. Play Protect may also ask you to confirm.

  4. Create your master password

    At least 8 characters; a long passphrase is better. Nobody can reset it for you, so write it down somewhere safe.

  5. Turn on what you want

    Fingerprint or face unlock is off until you switch it on in Settings. For autofill (Android 8.0 or newer), choose VaultPass as the autofill service in Android's settings, usually under Passwords and accounts; the menu name differs between phones.

Install on Windows

One installer with Java built in, so you don't need to install anything else.

From version 1.1.0, uninstalling keeps the vault. The data folder stays so a reinstall finds it. Delete that folder yourself to remove everything.

The current Windows release, 1.0.1, checks GitHub for a new version each time it opens and installs updates without checking a signature. You can turn the check off in Settings, under About, and update from this page instead.

  1. Download the installer

    Download installer gets the VaultPass-Setup file from GitHub Releases.

  2. Check the file

    Drop it into the file checker below, or run the PowerShell command there and compare the result with the SHA-256 above.

  3. Get past SmartScreen

    The installer isn't signed with a Microsoft code-signing certificate, so Windows shows "Windows protected your PC". Once the checksum matches, choose More info, then Run anyway.

  4. Install

    Pick a folder or keep the one the installer suggests. Your vault is kept in the data folder inside it.

  5. Create your master password

    At least 12 characters. Nobody can reset it for you, so write it down somewhere safe.

  6. Pair your phone, if you like

    With Windows 1.1.0 and Android 2.7.0 or newer: open Sync, scan the QR code with VaultPass on your phone, then approve the phone on the PC. If Windows asks, let VaultPass add firewall rules for private networks; that one step needs administrator approval.

Check the download

The checksum of the file you downloaded must match the SHA-256 GitHub publishes for it. Upper or lower case doesn't matter, but every character must be the same. If it doesn't match, don't install it.

In your browser

Drop the APK or the Windows installer here. Your browser computes the SHA-256 and compares it with the latest releases.

The file is read on your device and never uploaded.

Drop the downloaded file here

With a command

Run it in the folder the file was saved to.

Windows installer, in PowerShell Get-FileHash .\VaultPass-Setup.exe -Algorithm SHA256
Android APK, in PowerShell on Windows Get-FileHash .\VaultPass.apk -Algorithm SHA256
Android APK, on macOS shasum -a 256 VaultPass.apk
Android APK, on Linux sha256sum VaultPass.apk
