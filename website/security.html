CRYPTOGRAPHIC SPECIFICATION

Zero-Knowledge Architecture & Cryptographic Rigor

VaultPass assumes zero trust in external networks. Every cryptographic operation occurs locally on your Android device with hardware-backed integrity.

1 Multi-Tier Key Derivation Hierarchy

Step 1: Master Key (KDF)

Master password is processed using PBKDF2-HMAC-SHA256 with 300,000 iterations and a device-unique salt to derive a 256-bit Key Encryption Key (KEK).

Mitigates GPU & ASIC brute-force cracking
Step 2: Dual DEK Wrapping

A cryptographically secure random Data Encryption Key (DEK) is generated. It is encrypted twice: once with the derived KEK, and once with the Android Keystore hardware key for biometric unlock.

Android Keystore • TEE / Secure Enclave
Step 3: AES-256-GCM Payloads

All credential records, notes, and custom fields in the local Room SQLite database are authenticated and encrypted using AES-GCM with 128-bit authentication tags.

Guarantees confidentiality and ciphertext integrity

Constant-Time Verification

Standard string comparisons leak character-by-character validation timing. VaultPass enforces MessageDigest.isEqual(), ensuring verification latency is uniform regardless of input correctness, nullifying side-channel timing attacks.

In-Memory DEK Zeroization

Decrypted keys never sit idle in RAM. When the app is locked or when the auto-lock timeout fires via ProcessLifecycleOwner, the in-memory DEK byte array is overwritten with zeroes to guard against memory dumping exploits.

Incremental Lockout Protection

Local brute-force resistance is enforced with non-volatile DataStore counters:

  • • 5 Failed Attempts: 30-second cooldown
  • • 10 Failed Attempts: 60-second cooldown
  • • 15 Failed Attempts: 5-minute lockout
  • • 20+ Failed Attempts: 15-minute lockout

Window Protection & Auto-Clear

VaultPass calls WindowManager.LayoutParams.FLAG_SECURE to block screenshots and prevent credential exposure in Android’s Recent Apps switcher. Clipboard buffers are scrubbed on a configurable timer.

The .VPEX Encrypted Backup Schema

When exporting credentials for backup, VaultPass produces an encrypted .vpex archive using Base64 AES-GCM packaging. Each backup includes its own dynamic salt, initialization vector (IV), and HMAC checksum, allowing you to safeguard your data on cold storage drives without leaking plaintext.
